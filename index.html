How it works

  1. Adjust the tutor details, contact info, colors, images, and hours.
  2. Turn sections on or off so the page stays focused.
  3. Check the live preview for spacing and contrast.
  4. Copy the Canvas fragment, download a standalone preview page, or export the draft JSON.
  5. Import a saved draft JSON on another device if you have to switch mid-edit.
  6. Save in Canvas, then publish when it looks right.
