Quick workflow

  1. Fill in the tutor details, contact methods, hours, and any optional sections you want to keep.
  2. Turn sections off if they do not belong on this page.
  3. Use the live preview to catch spacing, contrast, and copy issues before export.
  4. Copy the Canvas fragment, download the standalone page for offline review, or export the draft JSON.
  5. Import that draft JSON on another device if you need to keep editing somewhere else.
  6. Paste into the Canvas HTML editor, save, and publish after one last check.
