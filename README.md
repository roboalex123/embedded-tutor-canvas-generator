# Embedded Tutor Canvas Generator

Static generator for the embedded tutor page used in Canvas.

## What it does
- Lets tutors edit prefilled page content
- Generates accessible, high-contrast HTML
- Shows a live preview of the final page
- Copies the HTML to the clipboard
- Gives simple Canvas paste steps

## Local use
Open `index.html` in a browser or serve the folder with any static server.

## Deployment
The live site is intended to be served at:

`https://varis.voss.industries/tc/embedded-generator/`

## Canvas steps
1. Open the Canvas page you want to edit.
2. Switch to HTML editor mode.
3. Paste the generated HTML.
4. Save and review the result.
5. Trim anything Canvas strips, then repaste if needed.
